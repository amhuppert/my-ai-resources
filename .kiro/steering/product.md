# Product Overview

Centralized AI workflow resources: skills, agents, hooks, and TypeScript-based installation tooling for Claude Code, plus a generated Codex packaging. A meta-repository that installs AI development infrastructure at user level (all projects) and project level (per-repo workflows).

## Target Use Cases

- Automating git workflows with AI-aware commits
- Persistent project context across AI sessions via steering files
- Optimizing AI instructions for token efficiency
- Standardizing AI development workflows across projects
